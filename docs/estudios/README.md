# Estudios de juegos comerciales

Fichas de lo que se ha medido en juegos comerciales para aprender técnicas. Cómo se hace: `docs/guias/estudiar-juegos.md`
(skill `gba-study`). Plantilla: [plantilla-ficha.md](plantilla-ficha.md).

Reglas: sólo cifras medidas y técnicas descritas con nuestras palabras. Aquí no entran código, desensamblado,
gráficos, capturas, música, textos, mapas ni volcados del juego; los datos en bruto se quedan en el scratchpad.
Las ROMs son volcados propios del usuario, fuera del repo.

Organización: una carpeta por juego (`docs/estudios/<juego>/`) con una ficha por tema (`fisica.md`, `video.md`,
`jefe-1.md`...). Una ficha sin la sección "Cómo lo haremos" no está terminada.
